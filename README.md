# Student Database Analysis using SQL 🗄️

## 📌 About the Project
This beginner-friendly SQL project analyzes fictional student records to explore marks, department performance, and course information using SQLite.

## 🎯 Objectives
- Retrieve and filter student records.
- Sort students by marks.
- Calculate average and highest marks.
- Compare performance across departments.
- Combine student and course information using `INNER JOIN`.

## 🛠️ Technologies Used
- SQL
- SQLite

## 📂 Project Files

| File | Description |
|---|---|
| `setup.sql` | Creates tables and inserts sample data |
| `student_analysis.sql` | Contains SQL queries for data analysis |

## 📊 Analysis Performed
1. Display all student records.
2. Find students scoring above 80.
3. Sort students by marks in descending order.
4. Calculate overall average marks.
5. Compare student counts, average marks, and highest marks by department.
6. Identify departments with average marks above 80.
7. Join student records with course information.
8. Count students in each department.
9. Find the lowest marks in each department.

## ▶️ How to Run
1. Open [SQLiteOnline](https://sqliteonline.com/).
2. Run `setup.sql` first to create the tables and insert sample data.
3. Run the queries in `student_analysis.sql`.
4. Review the results.

**Note:** Running `setup.sql` again resets the sample tables and data.

## 📁 Dataset
The project uses eight fictional student records created for SQL practice. The data does not represent real students.

## 📚 SQL Concepts Practiced
`SELECT` · `WHERE` · `ORDER BY` · `AVG()` · `MAX()` · `MIN()` · `COUNT()` · `GROUP BY` · `HAVING` · `INNER JOIN`
